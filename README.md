# Квіз «Black Friday: підбір курсів» — robot_dreams

3 питання → добірка курсів → перехід на акцію −40 %.

## Що де лежить

- `settings/texts.js` — усі тексти, посилання на акцію, адреса статистики.
- `settings/questions.js` — питання й правила підбору.
- `settings/courses.js` — курси.
- `app/` — логіка й дизайн, редагувати не потрібно.
- `stats/Code.gs` — скрипт для Google-таблиці статистики.

## Статистика

1. Створіть нову Google-таблицю, наприклад «Статистика: квіз Black Friday».
2. Розширення → Apps Script. Видаліть усе в `Code.gs`, вставте вміст `stats/Code.gs`, збережіть.
3. Угорі оберіть функцію `setup` → Виконати → дозвольте доступ до таблиці (Google попередить, що застосунок не перевірено: «Додатково» → «Перейти до…»).
   У таблиці з'являться аркуші «Події», «Проходження», «Зведення».
4. Розгорнути → Нове розгортання → тип «Вебзастосунок».
   Виконувати як: **Я**. Хто має доступ: **Усі**. → Розгорнути. Скопіюйте URL, що закінчується на `/exec`.
5. Відкрийте URL у браузері — має бути «Статистика квізу працює».
6. Вставте URL у `settings/texts.js` → `статистика` → `адреса: "…/exec"`.

Якщо змінюєте скрипт: Розгорнути → Керування розгортаннями → олівець → Версія «Нова» → Розгорнути. URL лишається той самий.

Статистика збирається лише з опублікованого сайту (GitHub Pages або Vercel), а не з файлу, відкритого з комп'ютера, і не з превʼю на claude.ai.

## Публікація на GitHub Pages

1. github.com → організація robot-dreams-code → New repository → назва `black-friday-quiz`, Public → Create.
2. «uploading an existing file» → перетягніть **вміст** папки (index.html, app, settings, stats, README.md), не саму папку → Commit changes.
3. Settings → Pages → Source: Deploy from a branch → Branch: `main`, папка `/ (root)` → Save.
4. За 1–2 хв квіз буде за адресою `https://robot-dreams-code.github.io/black-friday-quiz/`.

Щоб змінити текст: відкрийте файл на GitHub → олівець → правка → Commit changes. Сайт оновиться за хвилину.
